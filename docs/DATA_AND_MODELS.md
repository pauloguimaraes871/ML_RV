# Data and model inventory

What this repository tracks, what it deliberately does not, and how to get or
rebuild everything else. If a file a script expects is missing from a fresh
clone, it is listed in Section 2 (download it) or Section 3 (rebuild it).

Every input and generated dataset is pinned by SHA-256 in one of three tracked
manifests, so a downloaded or rebuilt file can be checked against the bytes the
results were produced from:

| Manifest | Written by | Covers |
| --- | --- | --- |
| `data/manifest_v3.csv` | `R/load_data.R` | JKP panel and S&P 500 (CRSP) datasets |
| `data/manifest_demiguel_v3.csv` | `R/load_demiguel_data.R` | DeMiguel nine-factor panel |
| `data/manifest_demiguel_costs_v3.csv` | `R/load_demiguel_costs.R` | DeMiguel stock-level cost data |

## 1. Inputs tracked in git

| Files | Content | Source |
| --- | --- | --- |
| `data/crsp.csv` | CRSP daily value-weighted market return (`vwretd`) | CRSP |
| `data/*.xlsx`, `data/*.xls`, `data/VIX.csv`, `data/OVX.csv`, `data/CSENT.csv` | Macro and uncertainty covariates (EPU, credit and term spreads, PPI, IP, T-bill, VIX, VXO, OVX, GPR, WTI, turnover, sentiment) | FRED, policyuncertainty.com, CBOE and others; each source URL is commented in `R/load_data.R` |
| `data/F-F_Research_Data_Factors_CSV.zip` | French three factors (risk-free rate for the S&P 500 backtests) | Kenneth French data library |
| `data/cluster_labels.csv` | Characteristic-to-cluster map (for example `age`: Low Leverage) used by the allocation and reporting code | Jensen, Kelly and Pedersen (2023) |
| `data/demiguel/raw/F-F_*` | French three and five factors and momentum, monthly and daily | Kenneth French data library, CRSP vintage 202608 |
| `data/demiguel/raw/q5_factors_*` | Hou-Xue-Zhang q5 factors, monthly and daily, 2024 and 2025 vintages | global-q.org |
| `data/demiguel/raw/Betting-Against-Beta-Equity-Factors-Monthly.xlsx` | AQR BAB, monthly | AQR data sets, as of July 2026 |

Download dates and the reasoning behind each DeMiguel source choice are in
`docs/DEMIGUEL_REPLICATION.md`, Section 1.

## 2. Inputs NOT tracked (download before building)

| Expected path | Size | Source | Hash recorded in |
| --- | --- | --- | --- |
| `data/[usa]_[all_factors]_[daily]_[vw_cap].csv` | ~225 MB | JKP factor returns, jkpfactors.com: USA, all factors, daily, value-weighted (capped) | `manifest_v3.csv` |
| `data/demiguel/raw/Betting-Against-Beta-Equity-Factors-Daily.xlsx` | ~31 MB | AQR data sets, BAB equity factors, daily | `manifest_demiguel_v3.csv` |
| `data/demiguel/raw/MainDataRep.mat` | ~476 MB | DeMiguel et al. (2024) replication package, Mendeley Data, DOI 10.17632/dmjfztbc4y.3 (CC BY 4.0); unmodified member of `ReplicationPackage.zip` | `manifest_demiguel_costs_v3.csv` (both the zip and the `.mat`) |

Providers revise history. If a fresh download hashes differently from the
manifest, the results will not reproduce byte for byte; keep the archived copy
(Section 5) as the reference.

## 3. Generated files NOT tracked (rebuild in this order)

| Step | Script | Writes | Size |
| --- | --- | --- | --- |
| 1 | `R/load_data.R` | `data/covariates_panel_*_v3.rds`, `data/covariates_spx_*_v3.rds`, `data/target_panel_v3.rds`, `data/target_spx_v3.rds` | ~70 MB |
| 2 | `R/load_demiguel_data.R` | `data/covariates_demiguel_*_v3.rds`, `data/target_demiguel_v3.rds`, `data/demiguel_returns_*_v3.rds`, `data/demiguel_rf_daily_v3.rds` | ~5 MB |
| 3 | `R/load_demiguel_costs.R` | `data/demiguel_stock_costs_v3.rds` | ~185 MB |
| 4 | `R/fit_models.R` | `models_v3/<sample>/` fitted backtests and ensembles, including `models_v3/demiguel/1927/` | ~2.3 GB |
| 5 | `R/oos_ports.R` | `ports/v3/<sample>/panel/<spec>/` (`all_ports.rds`, summaries, coverage) | ~1.8 GB with step 6 |
| 6 | `R/allocation_ports.R` | `ports/v3/<sample>/allocations/` second-stage allocations | see step 5 |
| 7 | `R/report_results.R`, `R/report_portfolio_inference.R`, `R/compose_sample_reports.R` | `latex_paper/results_v3/<sample>/data/` table inputs (the rendered `.tex` next to them is tracked) | ~540 MB |
| 8 | `R/demiguel_replication.R`, `R/demiguel_table*.R`, `R/demiguel_ml_inference.R` | `data/demiguel_table*_v3.rds`, `data/demiguel_ml_inference_v3.rds` (untracked) and `data/demiguel/*.csv` (tracked, small), from `models_v3/demiguel/` | ~10 MB |
| any | `R/plot_variables.R` | `diagnostics_v3/` covariate diagnostics | small |

Fitting (step 4) and the portfolio backtests (steps 5 and 6) take hours; runtimes
are noted in the scripts and in `docs/DEMIGUEL_REPLICATION.md`. Each fitted
object carries its own provenance record, so the bytes are not needed in git.

`data/covariates_1927v2.rds` and `data/covariates_1986v2.rds` are the one
exception: they are generated by `R/load_data.R` but stay tracked, because
`R/load_demiguel_data.R` reads them and their hashes are in
`manifest_demiguel_v3.csv`.

## 5. Where the untracked files live

The untracked inputs (Section 2) and the expensive outputs (`models_v3/`,
`ports/v3/`, `latex_paper/results_v3/*/data/`) are to be kept in external
object storage, keyed by their manifest hashes. Location: to be set up (record
the bucket and access instructions here when it exists). Until then, the only
copies are on the owner's machine.
